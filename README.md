# Student Dashboard Take-Home

This folder contains a lightweight one-page course planning dashboard for a college student. It includes:

- a searchable course catalog
- rating and level filters
- sorting options
- drag-and-drop support to move course tiles into the shortlist and final selection
- a shortlist for comparing classes
- a final selection area capped at four courses
- an expandable course detail modal

## Run locally

Open [index.html](index.html) directly in a browser, or serve the folder with a simple static server such as:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000.
